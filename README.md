# SOO Practice Room

A study tool for the CFPC Certification Examination's Simulated Office Orals (SOOs).

Contains the 26 official CFPC sample cases (Samples 1–27, skipping Sample 15), each with:

- A phase-by-phase walkthrough of the case
- The full marking guide
- A timed script for rehearsal
- A rehearse-with-a-timer mode

Plus a **Topic coverage** tab mapping cases to exam topics.

## Use it

Open the live site (GitHub Pages) or download `index.html` and open it in any browser. It is a single self-contained file — no account, no sign-up, nothing is sent anywhere. The only external request it makes is to Google Fonts.
